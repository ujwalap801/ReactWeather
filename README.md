# ⛅ Realtime Weather App

A responsive weather application built with **ReactJS** that fetches real-time weather data for any location. The app provides up-to-date weather conditions in a clean and intuitive interface with dynamic visuals using **Material UI**.

---

## 📝 Description

**Realtime Weather App** is a user-friendly frontend web application that retrieves live weather data using a free weather API. Built with **ReactJS** and styled using **Material UI**, it provides:

- Real-time temperature, humidity, and condition updates
- Search-based location weather lookup
- Dynamic weather icons and visual feedback based on current conditions
- Fully responsive layout optimized for both desktop and mobile

---

## ✨ Features

- 🌍 **Location-based weather search**
- 📡 **Real-time weather updates** via a public API
- 🌡️ Displays **temperature**, **humidity**, and **condition**
- 🎨 **Dynamic weather icons** and background themes
- 📱 **Responsive design** with Material UI
- ❗ Graceful **error handling** for invalid or failed API requests

---

## 🛠️ Tech Stack

- **ReactJS**
- **JavaScript (ES6+)**
- **Material UI**
- **OpenWeatherMap API** (or other public weather API)
